# Package prototype record callback

This fixture keeps Spiral prototype and instance selection at compile time, then projects the specialized residual across a linear package graph.

The graph is `model -> shared -> root`. The provenance sidecar assigns `Tuple0` to `model/state` and `method0` to `shared/advance`. Closure value and invoke helpers follow the typed dependency group required by the record-returning callback.

C, Rust and Delphi must exit with status 42. Rust and Delphi package outputs must contain no surviving prototype dictionary, Rust trait or impl, Delphi class, virtual dispatch or target-only receiver form.
